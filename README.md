# Recepiao — Cooking Recipes Website

Recepiao is a cooking recipe website built using Flask, Python, HTML, and CSS. It provides a simple platform for exploring cooking recipes and discovering ideas for preparing different dishes.

## Features

- Browse cooking recipes.
- View recipe details and cooking instructions.
- Simple and user-friendly interface.
- Dynamic web pages powered by Flask.

## Tech Stack

- **Python** — Backend programming
- **Flask** — Web framework
- **HTML** — Page structure
- **CSS** — Styling and layout

## Project Purpose

Recepiao was developed as a web development project to gain practical experience with Flask and Python while creating a website focused on cooking and recipes.

## Future Improvements

- Add recipe search functionality.
- Introduce recipe categories and cuisine filters.
- Improve the responsive design for mobile devices.
- Add functionality to save favorite recipes.
